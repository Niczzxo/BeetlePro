# Beetle Pro

Bangladesh boys-clothing e-commerce site: a same-to-same recreation of
https://beetlepro.framer.website/ with a full e-commerce layer.

- Live: https://niczzxo.github.io/BeetlePro/
- Repo: https://github.com/Niczzxo/BeetlePro
- Static single page (index.html) + assets/ (demo product photos) + robots.txt + sitemap.xml.
- Prices in BDT; payments shown: COD, bKash, Nagad, Rocket, Upay, card (gateway not yet connected).
- Docs: PRD, DESIGN, ARCHITECTURE, DATABASE, API, AGENTS, PLAN, SETUP, FEATURES, AUTH_SECURITY,
  MCP, INTEGRATIONS, TESTING, DEBUGGING.
