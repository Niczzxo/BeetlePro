# Beetle Pro: Integrations

- GitHub Pages: hosting/deployment from Niczzxo/BeetlePro (main / root, HTTPS enforced).
- Ink bleed theme changer: from the owner-supplied ink-bleed-theme-changer-main.zip
  (codemure-official, MIT): its WebGL2 shader/renderer/capture ported verbatim; only the ink
  colours are matched to this site's grounds (#F4F2ED / #1C1B17). Uses GSAP easing (power3.out)
  and html2canvas 1.4.1 from CDN for theme snapshots; the zip's CSS cross-fade is the fallback
  for no-WebGL2 / reduced-motion.
- Fly-to-cart: from the owner-supplied fly-to-cart-main.zip concept (public/concept.js) -
  photo pop-out, centre-crease fold into the file's PLANE_SVG paper plane, flight to the bag,
  commit on landing.
- Google Fonts via CDN.
- Not yet integrated: payment gateways (bKash/Nagad/Rocket/Upay/card), analytics, backend.
